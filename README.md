# Perishable Crop Queue Management System

University DevOps Engineering Module Project

## Developers

- Nikarsan
- Chandima

## Description

The Perishable Crop Queue Management System is a web application
for managing harvested perishable crop batches and their distribution.

The system uses FIFO (First-In, First-Out) processing to prioritize
older harvested crop batches during distribution and help reduce
crop wastage.
