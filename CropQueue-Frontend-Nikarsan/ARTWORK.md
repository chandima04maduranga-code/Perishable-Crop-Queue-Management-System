# CropQueue artwork

Created for the colourful frontend redesign with the built-in image-generation tool in generation mode. No API fallback or external stock service was used.

The original generated PNG files are included in `frontend/public/images/`. The harvest crate has a transparent background. The leaf logo (`cropqueue-mark.svg`), vegetable icons and interface icons are original SVG code.

Beautiful vivid emerald green, lime, warm golden sunlight and azure colours, detailed painterly edges, polished believable illustration, joyful and welcoming rather than childish clip art. Composition: keep the left third relatively calm and lighter, place the farmhouse and large rock toward the right, strong landscape detail in the lower half. No people, no text, no numbers, no letters, no logos, no UI, no borders, no watermark. This will be displayed as the hero banner of CropQueue.
